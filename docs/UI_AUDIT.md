## Unresolved Items & Environment Notes

- **Live Supabase Demo Credentials:** Local `.env.local` in this checkout sets `DEMO_MODE=true` without `DEMO_DOCTOR_EMAIL`, `DEMO_NURSE_EMAIL`, or `DEMO_ADMIN_EMAIL` / passwords (intentionally excluded from Git). Full remote Supabase integration tests (`scripts/integration-check.mjs`, full DB-RPC E2E scenarios) remain unexecuted against the remote project without demo credentials; UI, accessibility, offline, theme, and responsive verification ran against a local synthetic Supabase emulator (`http://127.0.0.1:54321`) without altering `.env.local` or production data.
- **Prettier Line Endings on Untouched File:** `npm run format:check` flags `src/app/api/patient/route.ts` (untouched by this revamp) due to Windows `core.autocrlf=true` line-ending differences; every modified and newly added file passes Prettier.
- **Clinical & Auth Gaps (Pre-existing):** Clinical validation, external SMS/VAPID push providers, Kannada/Hindi clinical translation review, and Supabase leaked-password protection remain outside this UI/codebase revamp scope (see `docs/KNOWN_LIMITATIONS.md`).
